# 🛒 E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **E-Commerce Sales Dashboard** developed using **Power BI**. The dashboard provides valuable insights into sales performance, product analysis, and customer behaviour. It helps business users monitor KPIs, identify trends, and make data-driven decisions through interactive visualizations.

---

# 🎯 Project Objectives

- Analyze overall business performance.
- Monitor revenue, sales, and customer growth.
- Identify top-performing products and categories.
- Understand customer purchasing behaviour.
- Build an interactive dashboard for business decision-making.

---

# 🛠 Tools & Technologies Used

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling (Star Schema)
- Excel Dataset
